# RoCE 单机布线规划需求

## 目标与范围

操作员在本机浏览器录入设备与端口参数，预览布线，再导出一份 Excel 施工表。安装依赖后可离线使用。当前版本内置 Leaf–Spine 上联和 Leaf–计算柜下联两套规则。

每个参与布线的物理口有 1–4 四个接线子端口，原 A 对应 1、2，原 B 对应 3、4。每对相连子端口占一行。计算柜可代表由 8 台 GPU 服务器组成的小超节点，柜口统一编号。柜内服务器与网卡映射、设备配置下发、Bond 配置和 Infrahub 写入不在本版本范围内。

## 输入参数

| 输入项 | 默认值 |
| --- | --- |
| Leaf / Spine / 计算柜数量 | 256 / 128 / 512 |
| Leaf 上联物理口范围 | 65–128 |
| Spine 物理口范围 | 1–128 |
| Leaf 下联物理口范围 | 1–64 |
| 每柜物理口数 / 每对 Leaf 接柜数 | 32 / 4 |
| Leaf / Spine / 计算柜编号前缀 | Leaf- / Spine- / 计算柜- |
| 三类设备型号 | 留空，可选填 |

设备从 1 开始编号，例如 Leaf-001。物理口范围包含起止编号。用户按设备规格填写可用端口范围，并确认设备支持所需的 四子端口接线模式。

## 固定连线规则

### Leaf–Spine 上联

- 单台 Leaf 按物理口升序排列，每口的 1、2 号子端口连同一台 Spine，3、4 号子端口连下一台 Spine。
- Spine 端从设定的起始口开始，每两台 Leaf 共用一个物理口。奇数 Leaf 接 Spine 子端口 1、2，偶数 Leaf 接 3、4。每组按子端口顺序一对一连接。
- 默认参数下，Leaf 1 的 `65:1`、`65:2` 接 Spine 1 的 `1:1`、`1:2`，`65:3`、`65:4` 接 Spine 2 的 `1:1`、`1:2`。Leaf 2 的 `65:1`、`65:2` 接 Spine 1 的 `1:3`、`1:4`。
- 最后一条上联为 Leaf 256 的 128:4 到 Spine 128 的 128:4。

### Leaf–计算柜下联

- 从 Leaf 1、2 开始，相邻两台 Leaf 组成一对。每组按设定数量依次分配计算柜，默认每 4 个柜用一对 Leaf。
- 柜侧奇数物理口接第一台 Leaf，偶数物理口接第二台。每个柜在两台 Leaf 上各使用同一段连续物理口。
- 每对物理口按 1 接 1、2 接 2、3 接 3、4 接 4 展开。计算柜 1 的 1、2 号口分别接 Leaf 1、2 的 1 号口。计算柜 2 的 1、2 号口分别接同一对 Leaf 的 17 号口。
- 最后一条下联为计算柜 512 的 32:4 到 Leaf 256 的 64:4。

## 校验、预览与导出

- 校验正整数、端口起止顺序、上下联端口重叠、设备前缀和 Excel 单表行数上限。
- Spine 台数须等于每台 Leaf 上联物理口数的两倍。每台 Spine 的每个物理口可为两台 Leaf 各提供两个子端口。每柜物理口数须为偶数，且下联物理口和 Leaf 对须足够容纳计算柜。
- 无效输入应显示具体原因并阻止导出。有效输入可预览各类链路的条数和部分示例。恢复默认参数后清空旧预览。
- 两段连接合在一张 XLSX 工作表，每对子端口连接一行，按 Leaf 编号、物理口和子端口号排序。冻结表头并启用筛选。

Excel 列顺序为 **Leaf 编号、Leaf 型号、Leaf 物理口、Leaf 端口信息、线缆标签、对端设备编号、对端设备型号、对端物理口、对端端口信息、链路类型**。端口信息显示 `物理口:子端口`，例如 `65:1`。线缆标签初始留空。

## 验收标准

- 默认参数生成 **131,072 行**明细，上联、下联各 **65,536 行**，下联对应 **16,384 组** 800G 物理口配对。
- 每个已使用的端点由设备编号、物理口和子端口号唯一确定。两端各自无重复占用，首尾连接符合上述示例。
- Spine 台数改为 127、每柜物理口数改为 31，或者将 Leaf 上联与下联口设为重叠范围，均应提示对应错误。
- 用户可以在本机界面完成预览和 Excel 下载。相同输入生成相同的布线明细与排序。

## 布线规则选择和 Excel 校验

生成页与 **校验布线表** 页面共用规则和输入参数。用户可选择仅 Leaf–Spine、仅 Leaf–计算柜，或两段合并。只校验所选规则的容量约束，按同一套算法计算预期接法。单段校验时只上传该段的明细。

校验页接受不超过 20 MiB 的 XLSX 文件。工作表名称留空时读取第一张。首行是表头，Leaf 端在左。必需字段为 Leaf 编号、Leaf 物理口、对端设备编号和对端物理口。可在物理口列直接写 `65:1`，或在物理口列填 `65`，端口信息列填 `1` 或 `65:1`。两处都含端点信息时必须一致。旧 A/B 表须先展开成新格式。设备编号应与所填前缀和编号格式一致。型号、线缆标签和其他备注可以保留，校验以两端端点为准。

逐行比较实际端点与预期端点。列表显示格式错误、计划外端口、错接、两端重复占用，以及缺失的预期链路。已有记录的错误显示 Excel 行号，缺失记录显示应补录的两个端点。可分页查看并下载完整问题清单。

验收时应将生成页导出的默认全量表重新上传，确认匹配 131,072 条且无问题。使用故意写错、重复和漏填的样例，确认各类问题和行号准确。
